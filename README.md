# Детская творческая школа «Арт-Умка» (г. Минск)

> Мобильно-ориентированное веб-приложение для публикации на GitHub Pages и интеграции в гибридное мобильное приложение React Native WebView (Snack Expo / Expo Go).

## 🎨 О проекте
Веб-приложение детской творческой школы «Арт-Умка» включает 3 ключевых логических экрана:
1. **Каталог курсов и направлений:** живая сетка программ (живопись 45 BYN, гончарный круг 50 BYN, мультипликация 55 BYN, робототехника 60 BYN, театр 40 BYN, скульптура 48 BYN) с фильтрацией по чипсам и промо-акцией «Пробный урок 0 BYN».
2. **Детализация программы курса:** подробный план занятий по 3 модулям, визитка педагога и интерактивная форма записи на бесплатный пробный урок.
3. **Личный кабинет родителя:** переключение между профилями детей («София, 7 лет» и «Миша, 5 лет»), виджет абонемента с остатком уроков, расписание ближайшего урока и цифровая семейная галерея детских рисунков с возможностью загрузки фото.

## 🚀 Стек технологий
- **HTML5:** семантическая разметка (`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<aside>`, `<footer>`);
- **CSS3:** модель Flexible Box Layout (Flexbox), стратегия Mobile First, относительные единицы измерения (`rem`, `em`, `%`, `vw`, `vh`);
- **JavaScript (ES6+):** динамическое переключение экранов без перезагрузки, фильтрация каталога, валидация форм;
- **GitHub Pages:** бесплатный хостинг статических сайтов по защищенному протоколу HTTPS.

## 📱 Интеграция с гибридным приложением React Native WebView
Данный сайт выступает в роли удаленного фронтенда (Web Core) и загружается в мобильном приложении через компонент `WebView` библиотеки `react-native-webview`:
```jsx
<WebView
  source={{ uri: 'https://<username>.github.io/<repository-name>/' }}
  javaScriptEnabled={true}
  domStorageEnabled={true}
  startInLoadingState={true}
/>
```
